# Juego Tres en Raya (Tic-Tac-Toe)

Un juego interactivo de Tres en Raya desarrollado con HTML, CSS y JavaScript.

## Características
- Modo 1 vs 1 local y modo contra la IA.
- Interfaz moderna y animaciones fluidas.
- Marcador de puntuaciones y reinicio rápido.

## Cómo ejecutarlo
Abre `index.html` en tu navegador web favorito.
